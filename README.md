# Тестовое задание Unity: "Симуляция сбора ресорсов дронами фракций"
[ссылка](https://drive.google.com/file/d/1Z9ksaOzp7o00gzfP_oCpQX2zymbtrRgZ/view?usp=sharing)

## Реализованные механики


### Поле
- 2 базы на противоположных сторонах 2D сцены
- 0-10 дронов, у каждой фракции
- Ресурсы, спавнящиеся по сцене

### Поведение дронов
1. Находит ближайший ресурс, не занятый другим дроном собственной базы
2. Движение к нему, избегая столкновений
3. Сбор резурса за заданное время
4. Возвращение на базу
5. Выгрузка "груза"
6. Повторение цикла

### Интерфейс
- Отображение кол-ва собранных ресурсов у каждой базы
- Ползунок кол-ва дронов (0-10) для каждой базы


## Архитектура


### Core элементы
- ObjectPool - реализация object pool, используется StarMaterial и Drone
- ReactiveVariable - для упращения работы работы с UI
- MainSceneEnterPoint - точка входа в сцену

### Объекты геймплея
- Ресурс (StarMaterial) - ресурс, который может собрать дрон
- Спавнер ресурсов (MaterialSpawner) - класс спавнящий ресурсы
- Дрон (Drone) - собирает ресурсы следуя своему 'ии'
  - имеет стейты (DroneBehaviour) для управления поведением
- База (Base) - точка базы для дронов, а так же класс, устанавливающий цели всем своим дронам

### UI элементы
- SiderView - управление числом дронов
- NumberView - отображение счета собранных ресурсов


## Используемые технологии


### Package и plugins
- Zenject
- HotReload
- NavMesh
